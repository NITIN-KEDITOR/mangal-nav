# MANGAL-NAV - The Mars Survival Compass

> On Earth we have Google Maps. On Mars, we have nothing. MANGAL-NAV fixes that.

**Challenge:** NASA Space Apps 2026 - Lucknow
**Team:** NITIN-KEDITOR

### The Problem
Future Mars astronauts can't navigate - no GPS, dust storms, -80°C, steep craters.

### The Solution
Interactive Mars map using REAL NASA data:
- **NASA Mars Trek Viking Mosaic** for map tiles
- **Curiosity Rover Photos API** for terrain
- Click 2 points -> Safe Route + Distance + Hazard Alert

### Why Different?
- Sanskrit Name: Mangal = Mars
- Indian Analog: We map Ladakh's Tso Kar lake as Mars test site (ISRO tested there)
- Survival Mode: Shows oxygen & thermal cost
